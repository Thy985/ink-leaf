把 `pickClipboardImage` 改为 `pickClipboardImages`（收集全部匹配项返回数组）；把 `insertImage(file)` 改为 `insertImages(files)`：

```js
let imageBusy = false;
async function insertImages(files) {
  if (mobileBusy) return;
  if (imageBusy) { toast('正在插入图片，请稍候'); return; }
  if (!files.length) return;
  imageBusy = true;
  try {
    const at = range(); // 光标在异步前捕获
    const refs = []; const failures = [];
    if (desktop) {
      if (!desktopPath) { toast('请先保存文档（Ctrl+S），再插入图片'); return; }
      for (const file of files) {
        try {
          const bytes = await file.arrayBuffer();
          const result = await desktop.writeImage(file.type, bytes);
          if (result?.ok) refs.push(`![粘贴图片](${result.filename})`);
          else failures.push(result?.message || '图片插入失败');
        } catch (error) { failures.push(error?.message || '图片插入失败'); }
      }
    } else {
      for (const file of files) {
        if (file.size > 2 * 1024 * 1024) { failures.push(`「${file.name || '图片'}」超过 2 MB，仅桌面版可插入本地图片文件`); continue; }
        refs.push(`![粘贴图片](${await readAsDataURL(file)})`);
      }
    }
    if (refs.length) {
      replace(at.start, at.end, refs.join('\n\n'));
      toast(refs.length === 1 ? (desktop ? `已插入图片 ${/* filename */ ''}` : '已插入内嵌图片') : `已插入 ${refs.length} 张图片`);
    }
    if (failures.length) toast(failures[0] + (failures.length > 1 ? `（另有 ${failures.length - 1} 项失败）` : ''));
  } finally { imageBusy = false; }
}
```

抽出 `readAsDataURL(file): Promise<string>`（onerror reject `'读取剪贴板图片失败'`）。paste/drop 调用点改为 `insertImages(pickClipboardImages(...))` / `insertImages(files.filter(...))`。单图 toast 文案保持与现有一致（桌面 `已插入图片 <文件名>`、web `已插入内嵌图片`），多图用新文案。

- [ ] **Step 2: window 级拖拽兜底**

```js
window.addEventListener('dragover', (event) => {
  if ([...(event.dataTransfer?.types || [])].includes('Files')) event.preventDefault();
});
window.addEventListener('drop', (event) => {
  if (![...(event.dataTransfer?.types || [])].includes('Files')) return;
  if (event.defaultPrevented) return; // 编辑器内已处理
  event.preventDefault();
  toast('请把图片拖到编辑器内插入，或用「打开」导入 Markdown。');
});
```

依赖冒泡次序：编辑器 handler 先执行并 preventDefault，window 层用 `defaultPrevented` 判重，避免双 toast。

- [ ] **Step 1: exportBodyHTML async 化（只读内嵌，不污染编辑器缓存）**

```js
async function exportBodyHTML() {
  const host = document.createElement('template');
  host.innerHTML = renderDocumentHTML(text(), { doc });
  for (const box of [...host.content.querySelectorAll('.ink-image')]) {
    const src = box.dataset.inkSrc || '';
    const kind = classifyImage(src);
    const cached = imageCache.get(src);
    let url = null;
    if (kind === 'data') url = src;
    else if (cached?.ok) url = cached.url;
    else if (kind === 'local' && desktop) {
      try { const result = await desktop.readImage(src); if (result?.ok && result.dataUrl) url = result.dataUrl; }
      catch { /* 文件丢失等，保持占位 */ }
    }
    const node = url ? exportImage(url, box) : /* 现有 missing 占位逻辑不变 */ null;
    box.replaceWith(node);
  }
  return host.innerHTML;
}
```

不改 `imageCache`（导出不得改变编辑器卡片状态）。web/Android 无 desktop 桥 → 本地图仍占位，行为不变。`exportHTML`/`exportPDF` 调用点补 `await`。
