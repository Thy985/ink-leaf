# 墨页 · 中文输入法与真机验证清单

本清单是发布前的人工验证门，覆盖桌面 e2e 与网页回归无法替代的部分：真实输入法的组合输入行为、真实系统栏与手势、真实文件提供方。每项通过记 ✔，发现回归记 ✘ 并附最小复现。

## Windows 桌面（Windows 10 / 11 x64）

安装 `dist/Inkstone-<版本>-Windows-x64-Setup.exe`，或免安装包解压运行。分别用 **微软拼音**、**搜狗输入法**（至少这两家）完成以下各节。

### 组合输入基本盘

- [x] 拼音连续输入多字候选，文字逐段上屏且段落预览不闪烁。
- [x] 候选未确认时按 Esc 取消，不留下半截字母。
- [x] 回删（Backspace）逐字删除拼音再删除已上屏文字，光标位置正确。
- [x] 选区替换：选中文字后直接打拼音，旧文字被替换且撤销一次可恢复。
- [x] 词库混输（如“墨页”一词一次上屏）后 Enter 换行，段落立即恢复预览。
- [x] 组合输入期间点击其他段落：草稿不丢、原段落不重排。

### 组合中触发的操作

- [x] 选词期间按 Ctrl+S / Ctrl+F / Ctrl+B：不报错、不在半途重排 DOM。
- [x] 选词期间打开查找替换面板或切换源码视图：组合结束后状态一致。
- [x] 选词期间点击「导出 HTML」「导出 PDF」：提示先完成选词，导出不执行。

### 图片与导出（v0.7 新增）

- [x] QQ/微信截图（Ctrl+Shift+A 等）后直接在文档内 Ctrl+V：图片文件出现在文档同目录，编辑器插入 `![粘贴图片](粘贴图片-….png)` 并显示真图。
- [x] 保存前的未命名文档粘贴截图：出现“请先保存文档”提示，不产生文件。
- [x] 拖拽图片文件进编辑器：同上落盘并显示；拖拽 .md 文件不插入图片。
- [x] 同一秒连续粘贴两张截图：文件名自动加序号，两张都显示。
- [x] 「文件 → 导出 PDF」：系统另存框扩展名锁定 .pdf；产物用浏览器打开显示公式（MathML）与内嵌图片；取消另存无残留文件。

### 文件与系统层

- [x] 文档关联：双击 .md 用墨页打开；最近使用列表出现应用。
- [x] SmartScreen 提醒与“未知发布者”提示符合预期（未签名开发版）。
- [x] 保存时另一程序占用文件：冲突提示出现，选择取消不覆盖磁盘。
- [x] 中文路径、中文文件名（如 `笔记/猫的秋天.md`）打开、保存、粘贴图片全链路正常。

## Android 真机（Android 8+ 与最新版各一台）

安装调试 APK，至少覆盖 **Gboard** 与 **搜狗**。

### 输入法

- [x] 拼音选词、连续输入、候选取消、回删、换行与桌面一致。
- [x] 候选栏不遮挡光标行；键盘弹出后可视视口正确，正文不被顶走。
- [x] 横竖屏切换保留草稿与光标；返回键先收键盘，再退出界面层级。
- [x] 组合中旋转屏幕或切后台再回来：文字不丢、组合状态不悬挂。

### 文件

- [x] 系统选择器导入 .md（本地与云提供方各一次），取消、非法编码、超 2 MB 均正确提示。
- [x] 导出 .md 成功后状态标记正确；导出失败不清除未导出状态。
- [x] 后台切换、系统回收、返回键退出后草稿恢复。
